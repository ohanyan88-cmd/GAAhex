# GAAhex — Favicon System

Compact glyph is intentional. At 16/32/48 px the seven-hex mark is illegible, so the favicon uses the compact 3-hex glyph: two Azure signal hexagons + one Gold destination hexagon — the v3.0 identity (signal -> destination) at its most legible small size. Cobalt structural cells are intentionally omitted at favicon size (they collapse into noise <=32 px); cobalt remains in all full-size lockups and the app icon. Deliberate and optimal, not an error.
