# 14-merch — Canonical Ownership

**Canonical apparel artwork:** `14-merch/apparel/` — the distinct per-placement renders
(`gaahex-merch-apparel-{frontchest|fullfront|back|sleeve}-{light|dark}.png`). This is the single
source for apparel placement art.

**Root of 14-merch** holds only the non-apparel merch masters: `gaahex-merch-vinyl.svg`,
`gaahex-merch-engraving-mono.svg`.

A prior uniform placeholder apparel set (every placement identical) was superseded by these
per-placement renders and preserved, not deleted, at `_archive/merch-superseded/apparel/`.
There is no longer any basename overlap between the root and `apparel/`.
