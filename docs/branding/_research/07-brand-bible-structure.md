# Brand Bible — structural patterns from 2025/2026 brand guide canon

Sources: WebSearch summaries 2026-06-04 (digitalpolo.com, frontify.com,
brandvm.com, spellbrand.com, akrivi.io)

## What a 2026 brand bible MUST contain

Distilled from multiple 2025/2026 brand-guidelines surveys, every working
brand bible has these sections in roughly this order:

### 1. Brand foundation (the "why")
- Mission / purpose
- Core values (3–5)
- Positioning statement
- Brand promise
- Audience personas (who this is for, who it isn't for)

### 2. Verbal identity
- Voice principles (4 max — Mailchimp's framework)
- Tone matrix (situation × tone shift)
- Naming & nomenclature (capitalization, product names)
- Do/don't copy pairs
- Vocabulary (words we use / words we avoid)

### 3. Visual identity — Logo system
- Primary lockup (wordmark + mark or wordmark-only)
- Secondary variants (stacked, horizontal, mark-only)
- Monochrome variants (mono cobalt, mono platinum)
- Construction grid (the unit of measure, usually X-height)
- Clear space rule (multiple of letterform)
- Minimum sizes (digital px, print mm)
- Approved backgrounds + contrast pairings
- Misuse examples (5–10 wrong-uses, called out visually)

### 4. Visual identity — Color
- Primitive scale (Tier 0)
- Semantic tokens (Tier 1)
- Family roles (D18 — Cobalt / Gold / Azure / Slate / Semantic)
- Light + dark theme pairings
- Accessibility contrast minimums
- Approved background → text combinations

### 5. Visual identity — Typography
- Display / UI / Mono families
- Type scale (with named tokens)
- Weight scale
- Line height + tracking
- Hierarchy patterns (page title → body → caption)

### 6. Visual identity — Iconography
- Library (single, locked)
- Stroke / fill rules
- Size scale
- Color rules (currentColor only)
- Do/don't

### 7. Visual identity — Motion
- Duration scale
- Easing curves
- "Brand-appropriate" motion (what we use)
- Forbidden motion (what we don't)
- Reduced-motion handling

### 8. Visual identity — Imagery
- Brand is graphic vs. photographic (GAAhex: graphic)
- If photographic: subject / palette / treatment rules
- Illustration system (if any)
- Data viz palette rules (D18 charts × palette)

### 9. Sound (skip — not relevant to GAAhex M1)

### 10. Usage — applications
- Product UI (already covered by design system standards 09)
- Documentation
- Email signatures
- Social profiles
- Partner materials
- Login / marketing surfaces

### 11. Misuse / DON'T gallery
- 5–10 explicit "this is wrong" examples with annotation
- Cross-referenced from each visual section

### 12. Legal / trademark
- Mark usage agreement (for partner / press use)
- Trademark notation
- Co-branding rules

## What "authenticity" means in 2026 brand bibles

Multiple 2026 brand-trend writeups (`growth.cx`, `huntandhawk.com`,
`overpass.studio`) converge on:

> "Authenticity will be the defining priority — with AI-generated content
> marketing saturating the market, SaaS brands must differentiate by
> showing transparency, human-led storytelling, and customer-centric brand
> values."

Lesson for GAAhex: this aligns precisely with the GAA+HEX honesty floor.
The family origin of the name, the partnership framing, the Armenian-
language layer — these are not embellishments; they're the brand. The brand
bible should **state plainly** that GAAhex is a family-named platform built
in partnership, and that the honest, human register is the actual product
of that origin, not a marketing veneer over it.

## What we DON'T need in GAAhex's brand bible (M1 scope)

- TV/broadcast guidance (no campaign work yet)
- Spokesperson rules (no spokesperson)
- Pitch deck template (separate deliverable when needed)
- Hiring brand / employer brand (premature — M1 is bootstrap)
- Out-of-home / billboard (not in M1 channel mix)
- Merchandising (not in scope)

Keep the bible focused on what the platform and the partner-facing surfaces
need. Expand only when a real channel demands it.
